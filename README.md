💿 BFF 俱樂部｜BAOBEIFREAKYFAHHH

BFF（BAOBEIFREAKYFAHHH） 是一個以 Frutiger Aero（千禧年代亮面科技美學） 為概念的互動式網站，結合音樂、拍貼與貼文分享，打造一個閃亮、清透又好玩的朋友交流空間。
網站以水藍 
#4cffff、螢光綠 
#48ff65、粉紅 
#ffa4fb 為主要配色，搭配亮面按鈕、毛玻璃面板、漂浮泡泡、網點與格紋圖案，重現 2000 年代電腦桌布般的夢幻氛圍。

✨ 網站介紹

🏠 首頁｜Home
以 BFF Logo 與閃亮按鈕迎接訪客，點擊 START 進入網站。

🪪 個人資料｜User Info
填寫使用者名稱、生日（自動顯示星座）及興趣標籤，建立自己的 BFF 檔案；點右上角頭像可隨時修改。

📰 貼文動態｜Home
左側為音樂播放器，右側為可捲動的貼文牆，點擊貼文即可查看完整內容與圖片。

🎵 音樂｜Music
收錄 6 首 Frutiger Aero 風格原創配樂，點選歌單即可播放，支援播放、暫停、重播與下一首；切換頁面時音樂不中斷。

📸 拍貼機｜Photobooth
三步驟完成拍貼：

開啟相機（3、2、1 倒數拍照）或上傳照片
從 4 款相框中挑選
自由加上 21 款貼紙，可拖曳、縮放、旋轉

完成後可儲存成圖片，或直接發佈成貼文，每一步都能返回上一頁重做。

✏️ 發文｜Post
輸入標題與內文、上傳圖片，日期自動帶入，發佈後立即出現在貼文動態。

🎨 設計特色
Frutiger Aero 亮面風格： 膠囊型亮面按鈕、毛玻璃面板、漂浮泡泡、網點與格紋背景。
旋轉光碟播放器： 播放音樂時，光碟會從專輯封面滑出並轉動。
原創視覺素材： 歌曲封面、相框、貼紙與裝飾圖案皆為本專案客製化設計。
音樂不中斷： 採用單頁式架構，在各頁面間切換時音樂持續播放。
響應式設計： 手機版自動調整排版，播放器變成底部的迷你播放條。
